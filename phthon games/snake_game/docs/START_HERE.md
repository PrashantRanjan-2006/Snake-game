## 🔧 QUICK TROUBLESHOOTING

**Problem: "Python not found"**
- Install Python from python.org
- Check "Add Python to PATH"

**Problem: "No module pygame"**
```bash
pip install pygame
```

**Problem: Game too easy/hard**
- Edit main.py: Change `INITIAL_SPEED = 10` to 5 (easier) or 15 (harder)

**Problem: No sound**
- This is normal! Sound is optional.
- See ASSETS_GUIDE.md to add sounds

**Problem: Game crashes**
- Run: `python test.py`
- This verifies installation
